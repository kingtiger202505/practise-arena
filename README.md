# 小小练习站 · 上海二年级教材练习

一个给上海二年级小朋友使用的静态练习站，面向 **2026—2027 学年第一学期**，覆盖语文、数学、英语，并保留即时反馈、进度、错题本和家长小报告。

## 当前范围

- 当前先制作各科**前 3 个教材单元**，共 9 个可练习单元、90 道题。
- 每个已开放单元都是一套约 100 分的练习：**10 道题 × 每题 10 分 = 100 分**。页面的单元卡、进度、完成提示和家长报告均按得分统计，不再按题数统计。
- 首页“开学起步”默认打开三科第 1 单元，合计 30 道题、300 分；“按学科练习”可以分别进入前 3 个单元。单元之间不会混题。
- 单元目录会继续显示后续单元，但未制作的单元会标记为“后续制作”并且不可点击，不会看起来像已有完整练习。

### 英语

用户已确认学校使用**沪教版（五四制·2024）新教材**，当前公开资料可以核对前三个单元标题：`My morning`、`My room`、`On the way`。由于公开页面没有提供足够可靠、完整的学生课文词表和正文，当前三个英语单元明确标为**标题词义 100 分入门练习**：只练已核对的单元标题词/短语，不擅自编写未核实的课文对话或词表，也不宣传为完整同步教材题库。

页面会持续提示英语的资料边界。若孩子书封、目录或老师进度不同，请暂停英语练习并以学校教材为准；上海学校也可能选用其他英语版本。

## 教材核对依据

以下来源用于核对版本、目录和单元名称，不把第三方教案当作官方课本正文：

1. [上海市教育委员会：2024 年秋季中小学教学用书目录](https://edu.sh.gov.cn/xxgk2_zdgz_jcjy_04/20240801/bb522c1b161b441281dba8bfe9296b36.html)及其[目录附件](https://edu.sh.gov.cn/cmsres/97/9705ef64871d45cf984f73d79cae5fd9/d5352cc408d180944636941826a5cdd3.pdf)：用于确认上海教材版本范围，并注意到二年级英语存在学校选用差异。
2. [统编版（五四制）免费目录页](https://www.dzskb.com/tbb54xxywes.html)：与公开目录信息交叉核对语文单元和课文名称。本项目不购买付费课件或教案，只使用可公开核对的版本和目录信息。
3. [沪教版数学二年级上册同步目录](https://www.zxxk.com/docpack/3530241.html)：用于核对“100 以内数的加减法（二）”“欢乐购物街”“表内乘法”等单元名称及部分课时线索。
4. [沪教版五四制·新教材二年级英语上册公开备课目录](https://www.zxxk.com/docpack/3513557.html)：用于核对英语单元标题。该页面是第三方资源集合，不是官方学生课本全文，因此英语题目严格收窄到标题词义。

## 使用

直接用浏览器打开 `index.html`，或在仓库根目录启动静态服务：

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

打开 `http://localhost:4173`。练习进度、答题结果和错题本会保存在浏览器的 `localStorage` 中，不需要账号或后端服务。当前应用使用 `little-practice-station-v4` 存储键，避免旧版题库和当前单元范围的答案污染新题库。

这是给孩子使用的练习工具，不是学校官方教材、作业或试卷的替代品；正式同步前请以学校发放的教材为准。
