# 小小练习站 · 上海二年级教材练习

一个给上海二年级小朋友使用的静态练习站，覆盖语文、数学、英语，并保留即时反馈、进度、错题本和家长小报告。

## 当前范围

- 背景学年：**2026—2027 学年第一学期**。
- 今日练习共 **25 题**：语文 8 题、数学 7 题、英语 10 题；每题对应一个已核对的上册单元。
- 语文按 2024 新教材的八个单元组织，题目使用目录中实际出现的课文和课文情节。
- 数学按沪少儿《数学（试用本）》二年级第一学期的七个单元组织，题目覆盖该单元目录中可核对的运算、人民币、乘法、方位、分类、搭配和复习内容。
- 英语单独标出版本边界：上海官方用书目录说明二年级英语由学校选用版本。本页目前只载入公开“沪教版（五四制·2024）新教材”备课目录中核对到的 10 个单元标题，并且题目只练标题里的词/短语；**没有把牛津上海版、新世纪版或未核对的英语词汇/课文擅自混进来**。

## 教材核对依据

以下来源用于核对版本、目录和单元名称，不把第三方教案当作官方课本正文：

1. [上海市教育委员会：2024 年秋季中小学教学用书目录](https://edu.sh.gov.cn/xxgk2_zdgz_jcjy_04/20240801/bb522c1b161b441281dba8bfe9296b36.html)及其[目录附件](https://edu.sh.gov.cn/cmsres/97/9705ef64871d45cf984f73d79cae5fd9/d5352cc408d180944636941826a5cdd3.pdf)：确认五四制二年级语文练习部分、沪少儿二年级第一学期数学试用本，并明确二年级英语由学校选用一种版本。
2. [统编版（2024）二年级上册目录核对页](https://www.51jiaoxi.com/yw/tb_c4069505/)：列出八个单元及课文，如《彩虹》《去外婆家》《数星星的孩子》《快乐的小河》等。它是第三方教材资源目录页，因此界面仍保留按学校书封核对的提示。
3. [沪教版数学二年级上册同步目录](https://www.zxxk.com/docpack/3530241.html)：列出“100 以内数的加减法（二）”“欢乐购物街”“表内乘法”“我的学校我的家”“分类”“数学广场”“复习”七个单元及部分课时标题。
4. [沪教版五四制·新教材二年级英语上册公开备课目录](https://www.zxxk.com/docpack/3513557.html)：列出 `My morning`、`My room`、`On the way`、`Playing sports`、`In the sky`、`In the sea`、`Seasons`、`Yummy fruit`、`The five senses`、`This is me` 十个单元。页面是第三方资源集合，不是官方学生课本全文，所以英语题目严格收窄到标题词义。
5. 上海市教委的[2026 年春季编写教学用书目录](https://edu.sh.gov.cn/cmsres/3a/3a555417ed2b47a38f730ca8c9f10881/9ba8430bf7e54d3e19fce9c17b45f5fb.pdf)用于交叉检查上海教材编写目录。它是春季目录，不能替代孩子所在学校的 2026—2027 第一学期选书确认。

截至当前实现，尚未获得用户所在学校、区和英语书封/版次，也没有把任何候选英语版本宣传为全上海统一教材。家长应先看书封和目录；如果英语单元不同，请不要把英语部分当作同步练习。

## 使用

直接用浏览器打开 `index.html`，或在仓库根目录启动静态服务：

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

打开 `http://localhost:4173`。练习进度、答题结果和错题本会保存在浏览器的 `localStorage` 中，不需要账号或后端服务。应用会使用新的 `v2` 存储键，避免旧版 9 题题库的答案污染当前题库。

这是给孩子使用的练习工具，不是学校官方教材、作业或试卷的替代品；正式同步前请以学校发放的教材为准。
